UnsourcedFlag

A small pill badge that discloses authored/usage guidance with no record in the project's source-tracking system — never a fabricated citation id, never silently asserted as if sourced.

Why this one, and why now

This channel's own faceless-video-craft skill mandates a disclosure flag for any on-screen claim/instruction with no record in the project's source system — "never a fabricated citation id" — and the concept genuinely converged independently across at least six shipped videos: pdrn-cellular-science, madecassoside-flat-matrix, centella-tiger-grass, retinal-clinical-dossier, mugwort-healing-herb, and (later removed once a real citation was found) red-ginseng-glass-glow. What never converged is the treatment: grep the actual shipped CSS and four different answers come back — pdrn-cellular-science and madecassoside-flat-matrix both render .uc-unsourced as bare text with no border, fill, or shape at all; retinal-clinical-dossier renders it in JetBrains Mono with no pill either; only mugwort-healing-herb (round 3.1, after a review flagged its own bare-text version as "genuinely plausible to misread as leftover template output") ships the bordered/filled pill shown here. So this isn't a case of the same component built five times identically and never cataloged (that's TermDefinition's story) — it's the opposite risk: a widely-shared concept with visibly inconsistent execution, most of it still carrying the exact "looks unfinished" defect one project already found and fixed. This entry harvests the fixed version as the recommended shared treatment, not as a description of an existing consensus — the other five projects still don't use it.

○ UNSOURCED — no record in this system
Jung et al. 2018 · PMID 29353040

Shown side by side deliberately — the two must never be confused. .uf-badge is ink-toned, circular-glyph-prefixed, no journal typography. .uf-cite is coral, pill-bordered, carries a real author/year/PMID. A viewer should be able to tell which is which without reading either string closely.

Field contract

{
  text: "○ UNSOURCED — no record in this system",  // the shipped default string —
                                                     // change the glyph/wording per project's
                                                     // own convention, keep the ink/border
                                                     // treatment and the "never coral" rule
  fadeInAt: 0.6,       // seconds into the scene's local timeline
  fadeInDuration: 0.4  // opacity 0 -> 1
}

No other fields — this is intentionally a single string in a fixed shell, not a multi-field data-driven component like TermDefinition or GradedScale. The one real per-project decision is timing: fire it while the unsourced claim is actually being said/shown, not before or after.

Status

SPIKE — not wired to a build pipeline. Matches this catalog's existing convention: a validated, self-contained visual reference (deterministic t-driven clock, seek-safe, no animation/rAF) ready to paste into a real HyperFrames composition, not yet a registry-installed component. The badge markup/CSS here is transcribed verbatim from mugwort-healing-herb's shipped .uc-unsourced (round 3.1) — the one project of six with this pattern that resolved it to a legible, non-template-looking shape. This is not yet a channel-wide convention; the other five projects listed above still ship the unstyled/inconsistent versions and would need an update to match.

How to use it in a new video: drop the .uf-badge markup and CSS into the scene, set fadeInAt to the moment the unsourced claim is spoken/shown, and — this is the whole point of harvesting it — check here before reaching for bare text or reinventing a treatment, the way six shipped projects each did independently.
