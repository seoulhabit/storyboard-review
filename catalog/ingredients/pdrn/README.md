# PDRN

Four takes on PDRN (polydeoxyribonucleotide), plus two reference images. See
[../../README.md](../../README.md) for how this fits into the wider catalog.

- **`pdrn-poster-spike.html`** — "PDRN Renewal." Branded hero poster (Trinity
  Medical Aesthetics), Traditional Chinese copy, 4-step / 7-benefit stat
  callouts.
- **`pdrn-poster-variation-spike.html`** — "PDRN Renewal Codex." Same 4-step /
  7-benefit content, reimagined around a glowing DNA double helix (canvas-drawn)
  on a dark biotech-lab palette instead of the soft pink bubble treatment —
  spec-sheet index (04/07) in place of bubble callouts, Trinity credit pulled
  back to a quiet line rather than a logo lockup.
- **`pdrn-skin-regeneration-spike.html`** — "PDRN Skin Regeneration." Not a
  poster — a 3-point mechanism explainer (Barrier Repair, Reduces
  Inflammation, Boosts Cell Renewal). Use this where the video needs to
  explain *how* PDRN works rather than show a hero poster for it.
- **`pdrn-poster-bubbles.png`** / **`pdrn-poster-helix.png`** — two visual
  motif options (reviewed together in `storyboard_pdrn-poster.html` at the
  repo root) that fed into the posters above.

A full HyperFrames project scaffold (`hyperframes.json`, real compositions)
for PDRN skin regeneration already exists at `../../../videos/pdrn-skin-regeneration/` —
these files are the design-reference layer that precedes it, not a
replacement for it.
