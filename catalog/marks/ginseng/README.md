# Ginseng Mark

Abstract root mark matched to a real reference photo: ringed neck, tapering
body, forked legs with root-hair tendrils, in sandy tan and umber on
porcelain ivory. Tilted 30 degrees left. Generated via Recraft AI
(provenance embedded in each file's C2PA metadata).

**`ginseng-primary.svg`** is the pick; `ginseng-alt-1/2/3.svg` are the
other directions explored alongside it.

Pairs with the [Ginseng ingredient
entry](../../ingredients/ginseng/README.md) — a standalone identity mark,
not a replacement for the "Red Ginseng: Two Routes" video it's linked to.
