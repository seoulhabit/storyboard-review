# PDRN Mark

Double-helix abstraction in clinical teal (`rgb(43,110,107)`) with a coral
accent strand (`rgb(224,139,114)`), on porcelain ivory. Reads immediately as
DNA — the cross-rungs are the tell, not just a generic twist.

**`pdrn-primary.svg`** is the pick. The other eight are the three revision
rounds kept for reference, not equal alternates to choose freely between:
round 1 established the twist, round 2 added the cross-rungs so it reads as
DNA rather than an abstract ribbon, round 3 smoothed to fewer, larger
facets for cleaner reproduction at small sizes. Generated via Recraft AI
(provenance embedded in each file's C2PA metadata).

Pairs with the [PDRN ingredient content](../../ingredients/pdrn/README.md)
— this is a standalone identity mark, not a replacement for either PDRN
poster.
