# SplitFaceProtocol

- **`splitfaceprotocol-spike.html`** — "Clinical Vector Map." A pure-SVG
  schematic of a split-face study design — no photography, so no lighting
  bias or "before/after" framing. Left half is `#control-arm` (untreated),
  right half is `#active-arm` (treatment), bilaterally symmetric and
  independently targetable/animatable. Grounded in `ING-PDRN-S004`'s
  clinical split-face trial (N=32, topical eye-area cream/serum). Same
  deterministic `t`-driven GSAP clock as the other components — see
  [../../README.md](../../README.md).

Use this wherever a claim needs to show *how the study was structured*
rather than just cite it — pairs well with EvidenceMeter or GradedScale
carrying the same `ING-PDRN-S004` claim alongside it.
