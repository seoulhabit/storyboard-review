GradedScale — Strict Enum Badge

Five discrete nodes, no interpolation between them. The engineering isn't the CSS — it's the gate: validateGradedScale() must refuse anything outside {1,2,3,4,5} before a single node paints, so a bad value kills the build instead of drawing a plausible-looking lie.

Hard enum

Only integers 1–5 render. No clamping a 0–100 score, no rounding 3.5 up or down.

No success color

Celadon marks every active node at every score. 1-of-5 must not read as failing, 5-of-5 must not read as a win.

Fails loud

Invalid input throws before a single node paints — no default grade, no last-known-good fallback.

Fixed label column

The label sits in a constant-width slot so stacked attributes keep their tracks in one column.
