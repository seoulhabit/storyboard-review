How to read this catalog

Kind — what the thing fundamentally is: component static composition mark photography / linked tooling
Control (components only) — how you drive it, not just how finished it is: ⏱ clock deterministic, seekable via a t value — safe for real renders
◧ select a discrete prop (a dropdown, an enum), no time axis
⚠ none no scrub interface yet — either nothing's been authored, or (flagged per-card) it plays on its own clock and isn't render-safe
Duration and a short field contract are shown for every clock/select component that has one documented — the point of harvesting a component is knowing what you can pass it without reading its source.

Data-driven components

Reusable, ingredient-agnostic. Loading a clock-control item auto-opens its debug scrubber if it's gated behind one — you shouldn't have to already know that flag exists to see it move.

Static compositions

Single-frame, ingredient-specific posters — not reusable components, no control axis by design.

Marks

Standalone identity/logo exploration — flat vector SVGs, not posters or components.

Photography

Raw stills, not components — for B-roll and thumbnails. Click a tile to open it full size.

Linked projects

No file lives under catalog/ — content already has a proper home in videos/ and isn't duplicated here.

Verification tooling

Shared scripts, not imagery or components — built once for a real project, worth reusing before the next one rebuilds the same check.

Gaps

Documented honestly as nothing-built-yet, rather than backfilled with a placeholder.
