  out on branch `claude/ectoin-explainer-rebuild-ad081f` — **not** a branch
  called `claude/snail-mucin-video-feedback-d3484b`.

`claude/snail-mucin-video-feedback-d3484b`) **do exist**, but as separate,
plain local branches, not checked out in any worktree — both pointing at the
same commit, `cc41fac` (the PR #11 merge commit), which is verified already an
ancestor of `origin/master` (`git merge-base --is-ancestor` checked directly).
They're harmless leftovers, safe to propose for cleanup later — but anyone
running `git branch -d claude/ingredient-pages-master-f9c42b` expecting it to
free up "the ingredient-pages-master-f9c42b worktree's branch" would be
looking at the wrong ref entirely. Flagging this explicitly so it doesn't
cause a mistaken deletion in a later task.
