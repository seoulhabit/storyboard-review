# Ingredient Fate story system

Version: **0.1.0**  
Stage: **first production prototype slice**  
Primary harvest source: `videos/collagen-where-did-it-go`

Ingredient Fate explains what an ingredient is in a specific form, where that
form can go, what changes along the route, how evidence survives scrutiny, and
which practical actions outrank optional products.

It consumes governed ingredient packs. It does not own ingredient facts,
product claims, narration, timing, hook copy or a complete storyboard.

## First component slice

| Component | Purpose |
|---|---|
| Format Vessel Pair | Keep neutral cream and oral-powder formats visually distinct without inventing products |
| Route Fork | Split one ingredient subject into two governed routes |
| Structure Scaffold | Carry intact, damaged, protected and partially-supported structure states |
| Skin Entry Gate | Compare molecular scale with an intact-skin boundary |
| Surface vs Structure | Show a surface film while the deeper structural layer remains unchanged |

Open `kit-preview.html` to review all five components with the Collagen fixture.

## Rules

1. The ingredient actor comes from the ingredient pack; a component must not redraw a replacement identity.
2. Route is a required field, not a decorative label.
3. Missing form, source, size or product information renders as unknown.
4. A surface state must not be visually merged with a dermal structural state.
5. Product vessels are neutral format actors and never imply a real brand, dose or efficacy.
6. Animation belongs to one paused host timeline. Component SVGs expose stable layer IDs and contain no autoplay.
