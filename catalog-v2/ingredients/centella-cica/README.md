# Centella / Cica — visual foundation card

This first Centella pack is intentionally **visual-first and evidence-light**. It gives formats a reusable botanical actor and a label-identity boundary without inventing efficacy claims.

## Use these repeatedly

- Recognition actor: three-leaf Centella silhouette plus one extract droplet.
- Source actor: harvested Centella sprig photograph.
- Truth mechanic: “Cica is a consumer cue; the exact declaration and extract version still matter.”
- Version mechanic: an incomplete ring that closes only when product-specific information is supplied.

## Best one-sentence position

Cica can point you toward Centella, but the exact ingredient declaration and extract details determine what is actually being discussed.

## Minimum visual recipe

1. Botanical actor.
2. Exact-label identity card.
3. Source image or source/process/version map.
4. Product-specific evidence record when available.
5. Boundary card.

## Current restriction

No efficacy evidence is promoted in this pack yet. A format may use the identity and source visuals, but it must bring its own approved claim records or remain at the label-literacy level.
