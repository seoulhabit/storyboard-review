# Fold & Spark Brand Mark

Not ingredient-specific — a flat vector logo proposal for a premium
educational brand: an angular fan symbol reading as pages caught mid-turn,
with a single yellow spark facet, on deep slate navy. Generated via
Recraft AI (provenance embedded in each file's C2PA metadata).

**`logo-primary.svg`** is the pick; `logo-alt-1/2/3.svg` are the other
directions explored alongside it.

"Fold & Spark" doesn't appear elsewhere in this repo yet — this reads as
an identity exploration for a possible education-focused brand or
sub-brand, not (yet) tied to any ingredient content, video project, or
existing name (SeoulHabit, Trinity Medical Aesthetics) already in use
here. Worth confirming with whoever's driving brand strategy before this
name shows up anywhere else.
