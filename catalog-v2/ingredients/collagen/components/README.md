# Collagen components

## Ingredient actor

`ingredient-actor.svg` is the canonical recognition actor. Inline it when a
HyperFrames scene needs access to the stable `cola-*` layer IDs. The host owns
all animation and must use one paused, seek-safe timeline.

## Identity and format map

`identity-format-map.svg` separates structural collagen, a topical formula,
an oral collagen-peptide format and post-digestion fragments. The map is an
identity/route boundary, not an efficacy diagram.

Both assets are illustrative and must not be described as microscopy.
