# Ingredient Mark (generic study)

Not tied to any one ingredient — the generic study that preceded the named
marks ([PDRN](../pdrn/README.md), [Ginseng](../ginseng/README.md)): a
leaf/droplet silhouette in jade with a single amber facet, on porcelain
ivory. Generated via Recraft AI (provenance embedded in each file's C2PA
metadata).

**`ingredient-primary.svg`** is the pick; `ingredient-alt-1/2/3.svg` are
the other directions explored alongside it. Folder name kept as committed
(`ingredient-mark` in the commit history) rather than renamed to something
catalog-specific, since it's what the design was actually called during
the exploration.

Useful as a fallback mark for an ingredient that doesn't have (or doesn't
need) a dedicated one of its own yet.
